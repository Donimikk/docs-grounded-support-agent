# Webhooks

Send notifications to multiple Discord channels with Pro webhooks.

Webhooks let Fyndit send alerts into Discord channels that you choose, so you can keep different alerts separated and easy to follow. This is a Pro feature only. If you want to send alerts to more than one Discord channel, webhooks are the cleanest way to do it.

## Who Can Use Webhooks

- **Free** - Not included.
- **Plus** - Not included.
- **Pro** - Included.

If you are on Pro, you can use webhooks to send notifications to multiple Discord channels. That can include channels in other servers that you manage, which is useful when you want one channel for buying, another for watching, or another for a separate team or setup.

## What Webhooks Do

- Send the same kind of alert to more than one channel.
- Keep different flows separated so your main DM inbox does not get crowded.
- Let you route alerts to another Discord server if you want a dedicated workspace for them.

## What To Expect

- Webhooks are for Pro users only.
- You can use more than one webhook if you want multiple output channels.
- The webhook just controls where the alert goes. It does not change how matching, buying, or monitoring works.

## Troubleshooting

- **Webhook option is missing** - You are probably not on Pro yet. Upgrade to unlock webhooks.
- **Alerts are not appearing in the channel** - Check that the Discord webhook or channel link is still valid and that the target channel still exists.
- **You want alerts in multiple places** - Create a separate webhook for each channel you want to receive notifications in.
