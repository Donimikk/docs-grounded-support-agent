# Dashboard

Start here for the main panels and quick actions.

The Dashboard is the main place to manage Fyndit. Use it first for everyday tasks, then fall back to the slash commands only if the Dashboard is unavailable or you prefer typing commands.

Open the Dashboard here: Open Dashboard

## What Each Button Does

| Button | What it opens | Fallback command |
| --- | --- | --- |
| Monitors | Your monitor groups, monitor links, filters, seller filters, and rules. | /monitors |
| Sessions | Your linked Vinted accounts, shipping settings, and wardrobe access. | /sessions |
| Session Groups | Groups of sessions used by automation rules. | /session_groups |
| My Info | Account usage, limits, and blocked sellers. | /my_info |
| Preferences | Language, embed settings, and cancel reason. | /preferences |
| Language | Quick language picker. | /preferences |
| Quick Actions | Test any item and pause or resume all rules. | Use the Dashboard button again, then Quick Actions |

## Quick Actions

- **Test Any Item** - Paste a Vinted item URL to see whether it would match any of your monitors.
- **Pause All Rules** - Stops every active rule from triggering until you resume them.
- **Resume Rules** - Turns all paused rules back on.

## What To Expect

- The Dashboard opens the same management panels you would reach through slash commands.
- Your changes are applied immediately, so you can manage monitors, sessions, and account settings without leaving the Dashboard.
- If a button is missing in a panel, it usually means that feature does not apply to the current item or your current plan.
- Feed colors are used to keep different notification streams separate, so you can split alerts into tidy lanes if you do not want everything in one inbox. You set a feed color per monitor group: Monitors, then the group, then Feed Colour. Each color corresponds to a different bot, and that bot delivers the group's notifications.

## When To Use Commands

Use the slash commands only as a fallback:

- The Dashboard message is unavailable.
- You prefer to jump straight into one panel.
- Staff asks you to use a specific command while troubleshooting.
