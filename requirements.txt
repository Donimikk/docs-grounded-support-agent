# Versions are PINNED with ==, not >=.
#
# Reason: every run stores a fingerprint of the prompt and a fingerprint of the
# code, so that two runs can be compared. Unpinned libraries destroy that
# meaning - a deployment a month later would quietly produce the same numbers
# from different code. The most sensitive one is langdetect: our MIN_CHARS and
# MIN_CONFIDENCE thresholds are measured against its behaviour, and changing it
# would shift them without anything announcing it.
#
# Raising a version is a deliberate act: change the number, run the tests and
# the eval, compare.
